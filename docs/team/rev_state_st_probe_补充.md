## 裁决：死刑维持，且证据加固

iter019"全局标量换算不可救"的结论在两个独立方向均被强化：

1. **上下文外推成立**：P_H1 的平坦曲线不是最差上下文的假象；Q_HepG2 呈单调恶化，
   全部上下文的最优 k∈{1,3,10}。不存在"换个数据集放大就有用"的世界线。
2. **逐靶 oracle 上限≈零**：允许每靶独立选 k（神仙校准）也只买回 nmae 0.2%（P_H1）
   / 4.0%（Q）。塌缩的真因确为逐基因 Δ 结构与 ref 不相关 + 靶集合选错基因（iter019
   结论）的复合，不是幅度标量错配。任何标量族方法（全局 k、per-target k、C2 式
   per-target g）作用在 State Δ̂ 上的天花板已实测封死。

**对 C3 的最终处置建议**：
- 维持降级——State ST 只作特征源（SE-600M 摘要特征喂 C2），不作为 Δ̂ 直接来源；
- 融合拓扑中的 α 路线（Δ̂ = α·Δ̂_state + (1−α)·Δ̂_v1）应关闭：若 α>0 的增益是靠
  幅度级混合实现，本探针证明该级上 State 无可提取价值；若靠方向级混合，其证据
  应由 v1-Δ̂ oracle-g 对拍（ml-expert 在途）承担，而非 State 融合。
- 唯一保留意见：State 的 pds 方向多样性（0.27 vs λ 系）未在本探针中被证伪其上限，
  但 pds oracle 也只有 +5.8%，不构成翻案量级。

**对 ml-expert oracle-g 对拍的镜像参照（可复用事实）**：
"给定方向结构弱（pds 0.50 vs λ 系 0.83）的 Δ̂ 源，逐靶标量幅度校准的 nmae 上限增益
≤4%，且不同指标要求互斥的 k。"C2 的 g 作用在 v1 Δ̂（pds 0.83）上，处境不同；但
y=log A 标签 + clip[0.5,3.0] 的设计应以此为先验：若 oracle-g 在 v1 Δ̂ 上同样只买到
<5% nmae 改善，C2 的价值主张应转向方向结构修正（如逐基因 Δ 混合）而非纯幅度。

**局限**：① k 网格粗（1/3/10/30/60），细网格或再多买 1-2%，不改变量级结论；
② oracle 无泛化约束，是上限的上限，可学习版本只会更低；③ R_Jurkat 未跑（省额度），
n=2 仍非 3，但 P/Q 来源（vcc2025 vs scperturb Nadig2024）、细胞系、幅度量级全部
不同，外推风险已远低于 iter019 时的 n=1。
