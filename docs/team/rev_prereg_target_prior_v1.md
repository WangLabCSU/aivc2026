## 1. 机制一：靶层确定性下调先验

- 适用对象：CRISPRi / ko 敲低扰动的靶基因；
- 施加点：**Δ̂ 构建期**对该靶基因施加确定性下调偏置；
- 幅度：由该靶点观测到的 **basal 证据**确定，设上限——basal 证据→幅度的确定性映射（统计量与函数形式）与上限值，均在**任何本地评估计算之前**随本预注册实现时一次性冻结，之后不因任何读数回调；

## 2. 机制：通路级证据条件化（p53 轴首发）

- 规则：p53 轴靶点只接受 **p53-WT 源**的方向票（hct116 / hepg2 / rpe1）；
- 排除出该轴靶点投票池：
  - **K562**：TP53 缺失（IFN 模块 basal **−0.15**）；
  - **jurkat**：p53 basal **0.023**；
- 排除按轴生效：仅改 p53 轴靶点的投票池构成，其他轴靶点不受影响；
- 与 cb v2.2 冻结的关系：这是投票池的**通路级条件化**，不改 ρ 定义、不改 w 公式（A.1）、不改 C2 池剔除（norman）等任何已冻结定义，属新增的一层条件化；
- 实现位置：投票池的通路级排除发生在**源加权之前**（先按轴过滤池成员，再进入既有 A.1 加权链）；与已落地的 gene_weights（source,gene）键（3920033，作用于加权期内）作用点不同，互不替代；
