## 三项焦点裁定

### (i) 行级 (target,ctx) 抽样 vs target 级分组 —— 认可行级

- target 级分组在 85–91% 跨 ctx 共存的现实下，会把 10% 留出靶从全部 5 个训练 ctx
  级联剔除（gwps 轴 ~91%×90% 同靶行损失），分层等比无从执行——spec 论证成立。
- 根本理由: 豁免方差必须与冻结锚同 regime。LOCO 冻结折本身就在"同靶近静态特征
  跨 train/test 共享"的属性下产生点估计；若改用 target 级分组测方差，方差来自比锚
  更严格、分布不同的 regime，2×std 判定对锚不可比。行级抽样保持同 regime，
  方差对锚才有解释力。

### (ii) 3 split_seed × 2 xgb seed 交叉设计与 6 模型合并 std —— 认可，附分解报告义务

- 全因子交叉（每个 split_seed 同时配对两个 xgb seed，非嵌套配对）是保独立性的
  正确结构: σ_seed 与 σ_split 可分离估计。ml-expert 提出的"配对是否够独立"疑虑不成立。
- 合并 std（6 模型样本标准差）作为豁免判定主尺度: 认可。统计含义 =
  "无害重跑（换训练子样本 + 换种子）下 rmse 的总移动尺度"，正是 R-1"劣化是否在
  噪声带内"的问句本身。合并 std ≥ 纯 split std（偏宽松读法），但定义在看到任何
  结果之前预声明并锁定，不构成事后放松。
- 条件 C1: 样本标准差 = ddof=1（n−1）。n=6 时 ddof=0 会低估 std 约 9%，必须预声明。
- 条件 C2: loco_multisplit.json 逐折必须记录 split_seed、xgb_seed、n_train_rows、
  rmse_model、rmse_g1、delta，并附汇总分解（每 split_seed 均值、seed 对内差、
  σ_seed = |rmse_full_s7 − rmse_full_s0|），使 REV 可独立重算合并 std 与
  split-only std 两种口径。
- REV 保留项（预声明）: 若豁免实际启用且分解显示 seed 分量占合并方差主导、
  致"split 方差"名实不符，REV 保留在豁免裁定前复核 split-only 口径的改判权。
  裁定主尺度仍为预声明的合并 std。
- 全量 seed=7 对照与冻结 seed=0 之差是 1 自由度的 σ_seed 估计，噪声极大——
  spec 已正确排除其进入豁免计算。

### (iii) 冻结锚不换 —— 认可，R-1 原文的唯一忠实读法

- "劣化幅度 < 2× 轴间标准差"中，劣化幅度 = 已入档冻结折叠的 delta_frozen
  （送审时已存在），方差是新增运行唯一允许贡献的量。若允许用新运行均值换锚，
  点估计也随事后数据漂移，"事后补测方差无效"的防线即被击穿。冻结锚是豁免通道
  保持狭窄的唯一机制，spec 表述与原文意图一致。
- 条件 C3（边界澄清）: 本运行**不得**重开已终裁的 aaf52c4 gate_report 的 G3 FAIL
  （该报告送审时无方差，豁免条件当时已判不满足，rev_R1_终裁.md 327b5ce 维持 FAIL）。
  方差基建只对**未来** gate_report 生效——未来报告送审时自带本方差，方满足
  "送审时已自带"的字面条件。今日发档决策（slot1=λ47, bizard-v0.2）不受本运行任何影响。

## 附加条件与备注

- 条件 C4: 90% 子采样模型的 rmse_model 绝对值预期略高于冻结折（训练行 −10%），
  该位移不得用作任何方向的证据（既非"模型变差"也非"模型稳健"），只有 std 进入豁免判定。
- 认可 spec §4 fail-fast: std 不达标 → "豁免通道确凿不可用"，不加大 split 数搜显著性
  （预注册双向锁死，不许放松亦不许收紧）。
- 知情备注（非判据）: n=6 样本 std 的置信区间很宽（χ²_5，95% CI ≈ [0.62×std, 2.45×std]）。
  std 窄幅未达阈值即终局；std 窄幅达标时，REV 将先核对 C1/C2 再裁定豁免。
