## 2. 机制裁定（探针给出的三个决定性读数）

1. **测试侧 OOD 机制被证伪，且是结构性定理**：V2（把测试侧 fp_self 从 1.0 钳到训练 max）
   与 frozen 六轴全部逐位相同。原因：xgb hist 树的分裂阈值只能落在训练分箱内（≤训练 max），
   任何 ≥ 训练 max 的测试值进入同一末箱、走同一路径。故"fp_self=1.0 超出训练支持 → OOD
   误路由"假说**不成立**——1.0 在行为上与训练 max 完全等价，一切测试侧重映射类适配注定无效。
2. **去 fp6 无修复能力**：仅 rpe1 改善（+0.1177→+0.0761，仍 FAIL）；jurkat/hct116 反而恶化
   （+0.1125/+0.1294）。fp6 对 jurkat/hct116 折是净收益，不是失效源。
3. **去 fp_self（V1）伤 PASS 轴**：hepg2 由 −0.0861 翻为 +0.0148（FAIL），gwps 增益从 −0.3518
   腰斩到 −0.1502；三 FAIL 轴仅微动（≤0.013）。fp_self 是真实信息载体，不可白拿。

**净结论：适配空间里所有"测试侧修补"与"去特征"方向已探明为空或负收益；唯一未测的
原理性类别是训练/测试语义对齐（V6）。**

## 3. 预注册 V6：fp_self 重定义为"最近邻 ctx 相关度"（本 spec 唯一新实验）

定义（全折统一、与 fold 无关，信息通道与冻结版完全同类——ctx 级 basal 相关标量）：

```
fp'_c(t) = corr(basal_t, basal_c)        若 t ≠ c   （与冻结版相同）
fp'_c(t) = max_{j≠t} corr(basal_t, basal_j)   若 t = c（自相关 1.0 → 最近邻相关度）
```

- 动机：把"自恒等 1.0"替换为"与最相似已知 ctx 的相似度"，训练/测试两侧语义一致，
  构造上消除 1.0 值域缺口（rpe1 测试值 0.7241 = 训练侧最大值，精确落在支持内）。
- 实现：`_build_ctx_feats` 的 self 分支一条改动；其余 31 维 FEATS、PARAMS、ROUNDS 不动。
- 运行：6 轴 LOCO，seed=0，与冻结折叠同 split（6 次训练，分钟级）。

**预注册判定（先于运行锁死，防事后解读漂移）**：

- 主判据：六轴全部 rmse_V6 ≤ rmse_g1（点估计）⟺ 该变体通过 G3 问句。
- 预期读数（基于 §1 探针上界声明，非判据）：rpe1 大概率仍 FAIL（V3 全去也仅余 +0.0761，
  V6 介于 frozen 与 V3 之间）；jurkat/hct116 预计不低于 frozen。
- **若任一轴仍 FAIL（预期主结果）**：(c) 终局关闭，出结果纪要入档——fp 家族适配空间
  （测试侧钳位 / 去自特征 / 去全族 / 语义对齐）四类全部证伪或负收益，冻结模型 G3 结论不变。
- 若六轴全部 PASS（低预期）：不强推发档；必须先 seed=7 复核 + 自带 6 模型 multi-split
  方差（v2.1-(a) 教训：单 seed 位移可达 ±0.07–0.18），再走 REV gate_report。
