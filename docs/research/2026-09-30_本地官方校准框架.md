## v3 更新：多重复锚点——归一化分数的 ref 选择方差（ML/AI 专家，2026-10-01）

**设计**：Q_HepG2 重建 3 个独立子采样参考（seed=11/12/13，协议同 mc_error.build_ref：固定 seed-0 的 100 扰动集——cell-eval2 要求 pred/real 扰动集一致，重抽扰动需连 pred 一起重生成，本轮不做；只重采细胞+NTC，各 ref 中位 48.5 细胞/扰动、1/100 靶达 400 上限，规模与 seed-0 完全相同）。每 ref 独立走全链路 baseline 臂 → prep-real-bundle（5 split-half 锚点）→ 跑 λ1.5 pred → score。4 读数 = seed0 + 新 3 ref。

**λ1.5 Q_HepG2 归一化分数（from_replicate，4 参考）**：

| ref | pds | mse | nmae | fid | reach | jac | overall |
|-----|-----|-----|------|-----|-------|-----|---------|
| seed0 | 0.631 | 0 | -0.166 | 0.577 | 0.098 | +0.164 | 0.2175 |
| seed11 | 0.655 | 0 | +0.241 | 0.630 | 0.134 | -0.142 | 0.2530 |
| seed12 | 0.695 | 0 | -0.273 | 0.637 | 0.107 | -0.061 | 0.1840 |
| seed13 | 0.638 | 0 | -0.213 | 0.631 | 0.096 | +0.136 | 0.2147 |
| **mean±std** | 0.655±0.028 | 0 | -0.103±0.233 | 0.619±0.028 | 0.109±0.018 | 0.024±0.150 | **0.2173±0.0282** |

**结论（方差分解，overall 层面）**：
1. **参考选择噪声 ≈ ±0.028，是细胞采样噪声（专家 B ±0.0017，raw 级、标度固定）的 16 倍**；即使标度固定只让 u 换 ref 重测，传播后也达 ±0.0078（1/(r-b)≈2.9 倍放大）。归一化 overall 的方差仅 ~8% 来自 u，**~92% 来自 0/1 端（b、r）随 ref 重建**。
2. 不稳定源集中在两个指标：**nmae（±0.233）**——u≈b（分子在 0 附近翻转符号）且分母 r-b 在 -0.13~-0.20 摆动（gate 后仅 62-64 扰动）；**jac（±0.150，符号都不稳）**——baseline 臂 b_jac 在 0.048→0.097 间 2 倍摆动被 1/(r-b)≈4 倍放大。pds/fid/reach 稳定（±0.02-0.03）；mse 恒被 clamp_low=0 钳在 0，无区分力。**1 端 r 本身跨 ref 稳定**（r_pds 0.849-0.856 / r_fid 0.649-0.658 / r_jac 0.312-0.328）——噪声在 0 端（generic baseline 臂）与 u 的放大，不在 split-half 锚点。
3. seed-0 的 0.2175 并非特殊值：4-ref 均值 0.2173±0.0282，单 ref 抽样可使 overall 移动 ±0.036（值域宽 0.069）。单 ref 读数对候选排序不可靠（0.02-0.03 级差异会被 ref 选择噪声淹没）。
4. cell-eval2 硬性拒绝跨 ref 评分（anchor real_fingerprint 校验无豁免）——不同 ref 的标度互不可比，多 ref 结果只能"各自 bundle 打分后取均值±范围"，不能混用标度。

**建议（bench 标准输出格式 v3）**：
- **采用 3-ref 均值±范围**作为归一化分数标准输出：`overall = 0.217 [0.184, 0.253]（3 ref）`；产物 `outputs/metrics/local_bench/mc_anchors.json`。
- 判读规则：单 ref 读数的 overall 差 **<0.04（≈√2×SD）一律平手**；<0.10 用 3-ref 配对均值判；同 ref 配对比较（共享 b/r/u 噪声）仍可用旧规则（专家 B）。
- **nmae/jac 的归一化值只报均值不做 gate**（符号不稳），两指标用 raw 值+配对比较；mse 归一化恒 0，从汇报表剔除或注明钳位。
- 待办：P_H1/R_Jurkat 复制本实验确认跨上下文普适性；若 pert 集也重抽（需每 ref 重生成 pred），方差只会更大——本测量是下界。

**成本**：每 ref ≈9 min（baseline 1.5 + bundle 5.7 + run 1.5 + score 0.1）；3 ref 并行（taskset 20 核/进程）≈10 min wall/上下文（bundle 一次性，跨候选复用；每候选每上下文 +3 次 run ≈ +4.5 min）。refs/bundle 中间产物在 /tmp/mc_anchors/，bundle 在 outputs/metrics/local_bench/mc_anchor_bundles/Q_HepG2_seed{11,12,13}/。
