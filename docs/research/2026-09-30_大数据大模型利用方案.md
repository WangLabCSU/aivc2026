## 1. State（Arc，L2 档）——下载已启动

- hf-mirror 实测可用：`SE-600M`(29GB)、`SE-100M`、`ST-HVG-{Parse,Tahoe,Replogle}`(57GB)、`ST-SE-*`(95GB)、`st-x-replogle-full`(39GB)。

## 2. Tahoe-x1（tahoebio，L3 预训练增强）

- 实测 hf-mirror 可用：`tahoebio/Tahoe-x1`，三档权重 70M/1B/3B（safetensors + vocab + collator 配置，支持微调）。scGPT 式 encoder，预训练于 Tahoe-100M（1 亿药扰剖面）。
- **定位：药扰≠基因扰动，不做主监督**。用途：① 基因/细胞嵌入作为 L1.5 回归的上下文特征（细胞系 baseline 嵌入）；② 在我们的 CRISPRi 池上微调其扰动头（对照/扰动 token 结构与 State 类似）；③ 与 State 集成。
- 已启动 70M 档下载（集成实验先行）；1B 档在 bench 显示增益后再取。
- 参考：[tahoebio/Tahoe-x1](https://huggingface.co/tahoebio/Tahoe-x1)、[GitHub](https://github.com/tahoebio/tahoe-x1)、[bioRxiv 2025.10.23.683759](https://www.biorxiv.org/content/10.1101/2025.10.23.683759v1.full)

## 3. scBaseCount（GCS 实测结构）

桶 `gs://arc-institute-virtual-cell-atlas/scbasecount/2026-01-12/`：
- `metadata/<mode>/<物种>/<dataset>/{obs_metadata,sample_metadata}.parquet` —— 全库研究级元数据（人类数据集目录已知存在，命名待一次精确 list 确认）
- `h5ad/<mode>/<物种>/<dataset>/*.h5ad` —— 按数据集存放，可只下选中的

**利用策略（按性价比排序）**：
1. **上下文指纹库（最高优先）**：只下 metadata parquet（每数据集 ~40MB obs + 27KB sample），筛 Perturb-seq 研究 → 汇总几百个细胞上下文的 NTC 画像来源清单 → 为 L1.5 上下文条件回归提供「数据集 → 与 A/B/C/D/E/F 相似度」特征。带宽成本 ~1-2GB。
2. **增量 CRISPRi 数据**：从 metadata 里筛我们签名库没有的 CRISPRi/Perturb-seq 数据集（尤其非造血/非癌细胞系——免疫学家建议的方向），按需下载其 h5ad 扩签名库 → 直接救 fid（多数据集方向一致性置信度）。
3. 不做全量下载（5 亿细胞、数 TB）。
