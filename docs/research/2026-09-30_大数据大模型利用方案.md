## 2. Tahoe-x1（tahoebio，L3 预训练增强）

## 3. scBaseCount（GCS 实测结构）

桶 `gs://arc-institute-virtual-cell-atlas/scbasecount/2026-01-12/`：
- `metadata/<mode>/<物种>/<dataset>/{obs_metadata,sample_metadata}.parquet` —— 全库研究级元数据（人类数据集目录已知存在，命名待一次精确 list 确认）
- `h5ad/<mode>/<物种>/<dataset>/*.h5ad` —— 按数据集存放，可只下选中的

**利用策略（按性价比排序）**：
1. **上下文指纹库（最高优先）**：只下 metadata parquet（每数据集 ~40MB obs + 27KB sample），筛 Perturb-seq 研究 → 汇总几百个细胞上下文的 NTC 画像来源清单 → 为 L1.5 上下文条件回归提供「数据集 → 与 A/B/C/D/E/F 相似度」特征。带宽成本 ~1-2GB。
2. **增量 CRISPRi 数据**：从 metadata 里筛我们签名库没有的 CRISPRi/Perturb-seq 数据集（尤其非造血/非癌细胞系——免疫学家建议的方向），按需下载其 h5ad 扩签名库 → 直接救 fid（多数据集方向一致性置信度）。
3. 不做全量下载（5 亿细胞、数 TB）。

## 5. 官方检查点结构重大发现（2026-09-30，PI 实测）

ST-HVG-Replogle 仓库内含逐上下文 held-out 检查点：`fewshot/{hepg2,jurkat,k562,rpe1}`（含该上下文训练）与 `zeroshot/hepg2`（hepg2 持出）。config.yaml 揭示官方跨上下文推理配方：
- `basal_rep: sample` + `basal_mapping_strategy: random`：基底=从对照细胞随机采样（与我们 L1.1 采样载体同构，官方背书）
- `predict_residual: true` + `loss: energy`（energy distance 分布损失）+ `pert_rep: onehot`
- HVG 空间（embed_key=X_hvg，~2000 基因），llama backbone（hidden 328×8层，小模型）
- 推理需随 checkpoint 附带的 `batch_onehot_map.pkl` / `cell_type_onehot_map.pkl`

**对 L2 的意义**：① `zeroshot/hepg2` 可直接在 bench Q_HepG2 上推理——官方强基线在我们 bench 上的读数 = bench 校准锚点；② 官方残差预测+采样基底设计验证了我们 L1.1 的载体选择；③ 我们的 18,533 全基因组输出 > 官方 HVG 空间，覆盖面是差异化优势。

## 6. scBaseCount metadata 筛选实测结论（2026-09-30）

- 人类样本 35,266 个全索引已入库（data/public/scbasecount_metadata/，含 h5ad 路径）。
- CRISPR 标签样本 6,804 行，但**逐一核查发现多为误标**：AICS-0090（iPSC 脑）实测无扰动列（"CRISPR"指细胞系构建），MDAMB/HEK293FT/TeloHAEC 同样需逐 SRX 核实研究设计。真正的 Perturb-seq 大头是 K562/RPE1/Jurkat（我们已从 scPerturb 持有）。
- **教训：scBaseCount 元数据的 perturbation 字段不可作为签名扩源的充分依据，必须 SRX→GEO→论文级核实。**
- 修正后的 fid 解法优先级：①用已有 7 源（gwps/rpe1/k562_ess/hepg2/jurkat/norman/adamson）做**响应基因级方向一致率**置信权重（ IMM 咨询中）；②scBaseCount 仅按论文核实后增源；③官方 zeroshot 检查点做 bench 校准（ML 专家执行中，注意其 pert 空间=essentialome 2,024，不含竞赛 300 靶，不能直接推理竞赛——竞赛级 State 需 state tx train 自训）。
