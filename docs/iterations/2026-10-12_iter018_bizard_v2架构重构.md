## State ST 首次 bench 结果（final.ckpt 04:57 EDT 落地后执行）

- **overall_raw=3.4402**（三上下文均值，nmae 轴未翻转越小越好）。
  P_H1: pds 0.5000/mse 0.9702/**nmae 51.10**/fid 0.4991/reach 0.0918/jac 0.1456；
  Q_HepG2: 0.5525/0.4897/2.1106/0.5027/0.1597/0.0576；
  R_Jurkat: 0.5069/0.4028/3.1010/0.5036/0.1958/0.0285。
- **P_H1 nmae=51.1 已定性：真实幅度塌缩，非管线 bug**。
  证据链：① pred 跨靶 |Δ| median P_H1=1.14 vs Q=5.57，而 ref 端 |Δ| median
  P_H1=70.2 / Q=153.7 → pred 幅度小 ~60 倍；② P_H1 全部 83 个有 nmae 的靶
  均 >1（median 54，max 100）→ 系统性而非个别靶；③ 跨靶 cosine 多样性
  pred 0.27 vs ref 0.07 → 方向结构尚可，缺幅度标定；④ H1 上下文离训练分布
  (K562+rpe1) 最远，零样本外推最差。
- **结论**：State ST 零样本 nmae/mse 轴全面弱于 λ 系基线
  （dualdeep_lam45 P_H1 nmae=1.008/pds 0.825；dualsrc_deep_lam45 Q nmae=0.911/pds 0.800），
  pds 也仅 0.50 打平 → **不可直接入提交链**（slot2 预案大概率不触发）。
  方向结构可用 → 后续以 ST→载体换算层（幅度校准）或作 XGB 幅度头输入源再评估。

## ML v2.0 设计稿交付（已收到，PI 已记录）

ML 专家交付 Bizard v2.0 架构设计稿，核心决策：

- **三层加模块拓扑**：
  C1 BizardNet v1 冻结方向/形状头（fid −0.032 冠军级，不动）；
  C2 XGBoost 逐(靶,上下文)幅度头 g=clip(Â/s_v1, 0.5, 3.0)（~13k 样本×50 特征,
  y=log A=top-200 |logFC| 均值，reg:pseudohubererror，方向全交 v1）；
  C3 State ST 重训（pert_rep=embedding + SE-600M 特征 → 300 未见靶零样本）。
- **融合**：Δ̂ = α·Δ̂_state + (1−α)·Δ̂_v1 再 × g·λ_global；
  RL 判定不适用（每日 2 发不可支撑在线探索）→ 可微代理损失 + TPE-BO 序贯探针搜索。
- **LOCO 双轴 + 硬 gate**：affine 校准预测 official ≥ +0.0886、LOCO fid 劣化 ≤0.02、
  nmae 不劣化、幅度 sanity、vcc prep 干跑绿、seed=0+rint。
- **排期**：10-12 晚 XGB-MVP + ST 预处理并行 → 10-13 State 重训+夜链 →
  10-14 双发预案（slot1=XGB 幅度探针过 gate 才发；slot2=State v0 LOCO 优于 v1 才发，
  否则留 λ 备选）。
- **待调和差异（PI 记录）**：ML 稿 State 规格（hidden 328/1+1 层/30–50k 步/cell_set_len 64）
  vs 当前运行（hidden 672/4+4 层/100k 步/cell_set_len 128）——以当前运行为准，ML 稿规格
  留作后续调参；pert 特征格式沿用现有 pert_features_se600m.pt（ML 稿 npz 不采纳）；
  ST→载体换算层须 gwps 留出靶逐位对拍后才可入提交链。
- **派发**：ML 专家先落 XGB-MVP（今晚）；CB 专家串行跟进（scbasecount 逐研究核实 +
  obs_metadata.parquet 重下 + 全数据特征化管线 + 签名聚合权重修订）；
