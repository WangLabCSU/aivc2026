# Bizard 架构规范 v1（bizard-v0.1 设计书）

> 2026-10-03 ｜ 立项：用户指令——深度学习+强化学习、鸟群群飞原理、多场景局部最优迭代指向全局最优、版本号 bizard-v0.1 起、目标排行榜前 3。
> 竞赛约束：六指标官方标度、每日 2 发、fid=-0.199 为最大失分项、官方最优 +0.0506（Rank 707）。

## 1. 设计理念：为什么是"鸟群"

竞赛评分是**六指标无权平均的多目标问题**，且 fid/jac 在本地不可精确复现——单模型单目标梯度训练已触及瓶颈（fusion v3 LOCO 持平 v2）。鸟群（swarm/PBT）原理的对应映射：

| 鸟群概念 | Bizard 实现 |
|----------|-------------|
| 鸟群个体（bird） | 一个完整的"预测器实例"= 特征配置 × 模型权重 × (λ, 置信参数) 的独立组合 |
| 局部觅食（local foraging） | 每鸟在**单一场景上下文**上局部优化（P_H1/Q_HepG2/R_Jurkat/S_RPE1/S_HCT116 五场景 = 五个局部生态位） |
| 适应度（fitness） | 该鸟在**全部五场景**的 affine 校准 overall 均值（全局适应度）+ 场景最差值（稳健性惩罚） |
| 群飞信息共享（flocking） | 每轮末：适应度 top-k 鸟的预测按权重融合（ soft-rank average），劣质鸟被替换（变异=新超参组合） |
| 全局最优收敛 | 多场景局部最优的凸组合 → affine 校准指向官方全局分 |

## 2. Bizard-v0.1 架构（三层）

```
L1 特征层（全数据接入）
  ├─ 6 CRISPRi 上下文签名（gwps 17k/hct116 深 17,358/rpe1/jurkat/k562_ess/hepg2）
  ├─ Tahoe 药扰签名（4,700 组 aux，w=0.3，has_sig 标志）
  ├─ NTC basal（A/B/C + 6 训练上下文 + a549/sw480）
  └─ 模块 one-hot（p53/IFN/EMT/E2F/线粒体/核糖体）+ 交互项

L2 学习层（每鸟 = fusion v3.5 骨干）
  ├─ XGBoost 分支（主任务 w=1.0 + Tahoe aux w=0.3）
  ├─ MLP 分支（256/128 SiLU Huber + has_sig 标志）
  └─ 鸟间差异（变异算子）：context-weight 分布 / seed / aux 权重 / top-K 稀疏度

L3 群飞层（Bizard 核心，v0.1 规模 N=6）
  ├─ 场景局部最优：每鸟绑定 1 个主场景（训练 context-weight 偏置该场景），
  │   在该场景 LOCO 上局部适应度最大 —— 多场景并行探索
  ├─ 群飞聚合：全局 pred = Σ w_b·pred_b（w_b ∝ softmax(局部适应度/τ)），
  │   每轮以五场景 affine overall 重排鸟权
  └─ 变异：末位鸟继承头鸟权重 + 高斯扰动（探索），防早熟
```

## 3. RL/搜索层：affine 奖励驱动的坐标搜索

- **奖励函数**（官方不可频繁查询 → 用已校准代理）：
  `R = clip(2.096·local_overall − 0.526, -0.11, +0.10) − 0.15·max(0, 场景min损失)`
  （affine v5：R²=0.989，LOO ±0.039；场景 min 项防 fid 型坍塌）
- **搜索空间**（每鸟 6 维）：λ∈{2.5,3.0,3.5} × context-weight 温度 × top-K ∈ {off,150,500} × aux 权重 × 置信 v2 开关
- **算法**：v0.1 用坐标爬山（每维 3 值网格，贪心推进）——n_eval ≈ 20-30 次 bench（bundle 复用后每点秒级+DE 级 15 分钟），一夜可完成
- v0.2 升级路径：CMA-ES / 真策略梯度（若搜索空间证明有连续结构）
